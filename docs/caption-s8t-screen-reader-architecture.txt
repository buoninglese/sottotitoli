CAPTION-S8T.HTML — SCREEN READER ARCHITECTURE DOCUMENT
========================================================
Written for a blind user. Describes every element on the page in tab order,
left-to-right, top-to-bottom, as encountered by a screen reader.

FILE STATS: 8,400+ lines, 20 script blocks, ~142 functions, 11 external JS deps.

LANGUAGE: Italian (html lang="it")
THEME: Supports light and dark mode via data-theme attribute

───────────────────────────────────────────────────────────────────
1. TOP BAR (always visible, sticky at top of page)
───────────────────────────────────────────────────────────────────

LEFT SIDE OF TOP BAR:

  [Link] "sottotitoli.pro"
    - The brand logo. Clicking goes to index.html (home page).
    - Rendered in Manrope font, 31px, bold.
    - ".pro" part is in accent color (cyan in dark, teal in light).

  [Link] "← Indietro"
    - Back button with left arrow icon.
    - Goes to panoramica.html (the dashboard).
    - Pill-shaped, bordered, muted color.

CENTER OF TOP BAR:

  [Button] 🇬🇧 (flag emoji for current caption language)
    - Clicking opens a dropdown row of 8 flag buttons to change language.
    - Languages: English, Italiano, Nederlands, Français, Deutsch,
      Español, Polski, Português.
    - Choosing a language shows a confirmation modal, then reloads.

  [Button] "Caption" (with closed-captioning icon)
    - Active by default. Indicates caption-only mode (no translation).
    - Has a pill style, cyan when active.

  [Button] "Translate" (with language icon)
    - Switches to translation mode.
    - When active, a second flag appears on the right for target language.
    - Shows a confirmation modal before switching.

  [Button] 🇮🇹 (target language flag, HIDDEN in caption mode)
    - Only visible in Translate mode.
    - Clicking opens a dropdown of 8 target language flags.
    - Languages: Italiano, English, Nederlands, Français, Deutsch,
      Español, Polski, Português.

  In Translate mode, there's also a source language flag between the
  Caption and Translate buttons (hidden in caption mode).

RIGHT SIDE OF TOP BAR:

  [Button] Theme Toggle (sun/moon icon)
    - Toggles between light and dark color theme.
    - Label: "Toggle color theme".

  [Button] Notifications Bell
    - Shows notification badge count when there are unread notifications.
    - Clicking opens a dropdown panel listing recent notifications.
    - Empty state: "Nessuna notifica" (No notifications).

  [Button] User Account (person icon)
    - Opens a dropdown menu with:
      - User display name (bold)
      - User email (smaller, faded)
      - Divider
      - "Home" link → index.html
      - "Panoramica" link → panoramica.html
      - Divider
      - "Minuti" — remaining minutes balance (e.g. "15 min")
      - "Crediti report" — remaining report credits (e.g. "3")
      - "Acquista crediti" link → purchase.html (blue, bold)
      - Divider
      - "Impostazioni" (Settings) link
      - "Aiuto" (Help) link
      - Divider
      - "Esci" (Logout) button — signs out, redirects to index.html


───────────────────────────────────────────────────────────────────
2. MAIN APP AREA (fills remaining space below top bar)
───────────────────────────────────────────────────────────────────

The main area is a horizontal-scroll container with 5 slide panels.
Only one panel is visible at a time. Arrow keys (Left/Right) navigate
between slides. The currently active slide is highlighted in the
right-side navigation dots.

SLIDE TITLE OVERLAY:
  A small text label at the top-center showing the current slide name.
  Example: "Captions", "Vocabulary", "Word Meaning", "Grammar Fix", "Topics".

RIGHT-SIDE NAVIGATION (vertically centered, 64px wide column):

  [Button] "Style" (palette icon with "Style" label)
    - Cycles between transcript display styles (2 options).
    - Positioned top-right, 34px circle button.

  [Button] "Captions" (closed-captioning icon + label)
    - Navigates to Slide 1 — the transcript panel. Active by default.

  [Button] "Vocab" (book icon + label)
    - Navigates to Slide 2 — vocabulary panel.

  [Button] "Words" (magnifying glass icon + label)
    - Navigates to Slide 3 — word meaning panel.

  [Button] "Grammar" (spell-check icon + label)
    - Navigates to Slide 4 — grammar correction panel.

  [Button] "Topics" (tags icon + label)
    - Navigates to Slide 5 — topic explorer panel.

LEFT-SIDE MODE BAR (vertically centered, 64px wide column, 5 buttons):

  These buttons change how you interact with words in the transcript.
  Only one can be active at a time. They are 56x56px squares,
  8px border radius, icon on top, label below.

  [Button] "View" (eye icon)
    - Read-only mode. Words are plain text. Clicking does nothing.

  [Button] "Edit" (pen-to-square icon)
    - Click any word to edit it inline. An input field replaces the word.
    - Press Enter or click away to save. Escape to cancel.
    - Edited words show an underline.
    - In translation mode, editing triggers re-translation.

  [Button] "Save Words" (book icon)
    - Click any word to save it to your personal word bank.
    - Saved words highlight in green.
    - Click again to remove.
    - Also works on translated/translation-column words.
    - Shows toast: "✓ Added: [word] ([language])"

  [Button] "Save Lines" (star icon)
    - Click an entire sentence line to bookmark it.
    - Bookmarked lines get an amber left border.
    - Click again to un-bookmark.
    - Bookmarked lines can be viewed via the bookmark panel.

  [Button] "View POS" (tags icon)
    - Shows each word with its part-of-speech tag as a colored bubble.
    - English only (requires Penn Treebank tagger).
    - Colors: Nouns=blue, Verbs=green, Adjectives=pink, Adverbs=purple,
      Prepositions=amber, etc.
    - Hidden for non-English languages.


───────────────────────────────────────────────────────────────────
3. SLIDE 1 — CAPTIONS (transcript panel)
───────────────────────────────────────────────────────────────────

This is the main viewing area for transcribed sentences.

  The panel shows a scrollable list of finalized transcript lines.
  Each line displays:
    - A timestamp (e.g. "14:32:05") in monospace font, muted color.
    - The sentence text in the chosen caption language.
    - Action icons appear on hover:
      - Copy button (copy icon) — copies the sentence to clipboard.
      - Delete button (trash icon) — removes the sentence.

  In translation mode, each line splits into two columns:
    - LEFT: Original source text (with timestamp).
    - RIGHT: Translated text in the target language, with loading
      spinner while translating.

  There are 2 caption styles (toggled by the Style button top-right):
    - Style 1 (cap1): Minimal — timestamp on left, text on right.
    - Style 5 (cap5): Dashboard cards — floating, rounded, shadowed.

  Placeholder text when empty: "Previous sentences will appear here…"


───────────────────────────────────────────────────────────────────
4. SLIDE 2 — VOCABULARY (POS Tags + CEFR Levels)
───────────────────────────────────────────────────────────────────

This slide has a left-right split layout.

LEFT HALF — POS Tags:
  Title: "POS Tags"
  Content: Words from the transcript grouped by part of speech.
  Each group shows:
    - POS name (e.g. "Nouns (12)") in its color.
    - Small colored chips for each word.
  Groups: Nouns, Verbs, Adjectives, Adverbs, Prepositions,
    Conjunctions, Pronouns, Auxiliaries.
  Placeholder: "Start speaking to see words grouped by part of speech."

RIGHT HALF — CEFR Levels:
  Title: "CEFR Levels"
  Content: Horizontal bar chart showing word distribution across
    CEFR levels (C2, C1, B2, B1, A2, A1 — top to bottom).
    Each bar shows the level name, percentage, word count.
  [Button] "📄 Download CEFR Report (PDF)"
    Generates a printable PDF report with CEFR breakdown and
    vocabulary by part of speech.
  Hidden data elements (for JS):
    - statLines, statWords, liveWpm, liveLexDiv, liveFillersPerMin


───────────────────────────────────────────────────────────────────
5. SLIDE 3 — WORD MEANING (synonyms + definitions)
───────────────────────────────────────────────────────────────────

Also a left-right split layout.

LEFT HALF — Word Cards:
  Filter pills at top: ALL, N (Nouns), ADJ (Adjectives), V (Verbs).
  Content area: Click a line in the transcript (Slide 1) to populate
    word cards here. Each card shows:
    - The word (large, bold).
    - Part of speech.
    - IPA pronunciation.
    - Definition text.
    - Frequency bar.
    - Save button (+) and bookmark button (☆).
    - Synonyms list (expandable).
  Placeholder: "Click a line → to see word cards here."

RIGHT HALF — Transcript Sidebar:
  Title: "Transcript"
  Font size controls: A⁻ / 15px / A⁺ buttons.
  Content: Compact transcript line list. Click a line to populate
    the left-side word cards with that line's words.
  Placeholder: "No transcript yet."


───────────────────────────────────────────────────────────────────
6. SLIDE 4 — GRAMMAR CORRECTION
───────────────────────────────────────────────────────────────────

Left-right split with stacked sections on the left.

LEFT COLUMN — TOP SECTION (35% height):
  Title: "What Changed"
  AI engine badge (e.g. "🧠 English → LanguageTool")
  Two retry buttons (hidden until grammar check runs):
    "🔄 Try Llama 3.3" and "🔄 Try Llama 4"
  Explanation text area: Shows what grammar changes were made
    and why (e.g. "Changed 'he go' to 'he goes' — subject-verb
    agreement, third person singular").
  Placeholder: "Select a sentence → to see grammar corrections
    and explanations."

LEFT COLUMN — BOTTOM SECTION (65% height):
  "Corrected" box: Shows the grammar-corrected version of the
    selected sentence (accent color, larger font).
  "Original" box: Shows the original sentence (muted, smaller,
    semi-transparent).
  [Button] "💾 Save to Error Bank"
    Saves the grammar error to a personal error bank for review.
    Disabled until a grammar check is run.

RIGHT COLUMN — Transcript Sidebar:
  Title: "Transcript"
  Font size controls: A⁻ / 15px / A⁺ buttons.
  Content: Compact transcript line list with grammar check buttons
    (checkmark icon) on hover. Click a line to run grammar check.
  Placeholder: "No transcript yet."


───────────────────────────────────────────────────────────────────
7. SLIDE 5 — TOPIC EXPLORER
───────────────────────────────────────────────────────────────────

Left-right split. English only.

LEFT HALF — Topic Donut Chart:
  Title: "Topics"
  Content: SVG donut chart showing topic distribution from
    the transcript (e.g. "Food and drink", "Travel", "Work").
    Each segment is a different color, clickable.
    Below the chart: legend list showing topic name, word count,
    and percentage. Also clickable.
  Placeholder: "Start speaking to see topic distribution.
    English only · updates every 30s."
  Status messages for: no transcript yet, analyzing spinner,
    API unavailable (cold start).

RIGHT HALF — Words by Topic:
  Title: "Words by Topic"
  Sort dropdown: "By frequency" or "By level"
  Content: Word chips with CEFR-level color badges.
    Clicking a topic in the donut/legend filters this list.
  Placeholder: "Click a topic → to see words."


───────────────────────────────────────────────────────────────────
8. BOTTOM CAPTION BAR (always visible, fixed below main area)
───────────────────────────────────────────────────────────────────

LIVE CAPTION BOX:
  A large rounded rectangle (border-radius 34px) that displays
  the current live speech-to-text in real time.
  The text is centered, large (font-size 45-65px adjustable),
  using the Inter font. Max 2 lines of text.
  Placeholder before first speech: "Speak to see subtitles…"

  TOP-RIGHT CORNER OF THE CAPTION BOX (3 small buttons):

  [Button] "A55" (Font size toggle)
    - Shows current font size inside the A (45, 55, or 65).
    - Cycles through 3 sizes: 45 → 55 → 65 → 45.
    - Pill-shaped, muted border, 13px font.

  [Button] "🪄 Fix" (Magic Fix toggle)
    - Toggles AI grammar correction on finalized sentences.
    - When OFF: shows "Fix" in muted color.
    - When ON: shows "On" in cyan/accent color.
    - Pill-shaped, sits between font size and palette buttons.
    - Persisted in localStorage.

  [Button] "🎨" (Live caption style cycle)
    - Cycles through 3 background styles for the live caption box:
      1. Cinema — dark rounded pill with soft glow (99px radius)
      2. Neon — yellow text with thick dark outline, transparent bg
      3. Glass — frosted blur translucent background
    - Small rounded button, 14px palette icon.

TRANSPORT CONTROLS (below the caption box, centered row):

  [Button] "🎤 Ascolta" (Start/Stop session)
    - Green glass button. Starts the microphone and speech recognition.
    - During session: becomes "⏹ Stop" (red glass button).
    - Label changes based on session state.

  [Button] "⏸ Pausa" (Pause)
    - Amber glass button. Only visible during active session.
    - Pauses speech recognition. Becomes brighter when paused.
    - Click again to resume.

  Timer: "00:00"
    - Session elapsed time. Monospace font, centered, 16px.
    - Counts up during active session.

  [Button] "⏹ Stop" (Stop session)
    - Red glass button. Only visible during active session.
    - Stops recording, saves the session, shows a toast:
      "✓ Sessione salvata" and a post-session overlay.

  Mic Status Indicator:
    - Small colored dot + "Mic Off" / "Mic Live" / "Requesting…" /
      "Blocked" / "Error" text.
    - Dot colors: gray=idle, amber=requesting, green=live,
      red=blocked/error, with pulse animation when live.


───────────────────────────────────────────────────────────────────
9. HIDDEN ELEMENTS (shown conditionally)
───────────────────────────────────────────────────────────────────

POST-SESSION OVERLAY:
  Appears when a session ends. Dark blurred backdrop.
  Card with "⚡ Sessione completata" heading.
  Shows word count ("N parole trascritte").
  Link button "Vai ai Report AI" → panoramica AI reports section.
  Auto-dismisses after 10 seconds.
  Has an X close button.

CONFIRM MODAL:
  Used for language switches and mode switches (Caption/Translate).
  Dark blurred backdrop, cyan-gradient card.
  Shows a globe icon, title, message, and two buttons:
    - "Annulla" (Cancel) — outlined, muted.
    - "Cambia" / "Switch" / "Apri" — solid accent color, bold.
  Also usable with keyboard: Enter confirms, Escape cancels.

WORD DEFINITION POPUP:
  Appears when clicking a word in the transcript or word bank.
  Shows: word, POS tag, definition text, IPA pronunciation,
    frequency bar.
  Action button: "+ Add to Bank" (toggles to "✓ Added" when saved).
  Close button (X) top-right.

BOOKMARK PANEL:
  Opens from a bookmark icon. Lists all bookmarked sentences
  with star icon, timestamp, text preview, and sentence number.
  Click a sentence to un-bookmark it.
  Empty state: "No bookmarked sentences yet. Enable Save Lines
    mode and click a line to save it here."

DUO+ JOIN SCREEN (hidden by default, shown when joining a room):
  Full-screen overlay with:
    "🎤 You've been invited" heading.
    "Join [host name]'s caption room" message.
    7 language pills for your language.
    Text input for your name (max 20 characters).
    "🎙 Join Room" button.
    Theme toggle button top-right.
