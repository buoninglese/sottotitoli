## Font Summary (active production use only)

| Font | Weight Range | Where Used |
|------|-------------|------------|

| **JetBrains Mono** | 300–800 | All numeric values, stats, gauges, timestamps |
| **Bebas Neue** | (single weight) | Logo, header labels (caption & traduzione) |
| **Work Sans** | 300–700 + italic | Body on traduzione page |
| **Manrope** | 300–800 | j7b alt caption mode |
| **Noto Serif JP** | 300–600 | Speaker bubbles mockup (#27) title only |

| **Montserrat** | 300–900 | Legacy blog/404 pages only |

## Fonts Loaded But Not Actively Used (production)
- **Playfair Display** — Loaded in studio-caption.html but no elements use it
- **DM Serif Display** — Same as above
- **Geist Mono** — Loaded in studio-caption.html & traduzione.html but no elements use it
- **Instrument Serif** — Only in mockups

## Recommendation
1. Remove unused Google Fonts imports from production pages to reduce load time:
   - `studio-caption.html`: Remove Playfair Display, DM Serif Display, Geist Mono (not actively used)
   - `studio-traduzione.html`: Remove Geist Mono, Manrope (not actively used)
2. **Inter + JetBrains Mono** cover 95% of production needs
3. Keep **Bebas Neue** for logo branding
4. Keep **Work Sans** on traduzione (it's the body font there)
