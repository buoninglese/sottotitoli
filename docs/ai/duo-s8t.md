# DUO-S8T.MD — Agent Reference for duo-s8t.html

> **Created:** 2026-08-04  
> **File:** `duo-s8t.html` (~990 lines)  
> **Purpose:** Real-time dual-language caption display via WebSocket. Receives captions from `caption-s8t.html`, translates them client-side, and displays in adaptive layouts.  
> **Status:** Stable. Safe for private 1-to-1 use. 8 hotfixes shipped (2026-07-25).

---

## 1. What It Does

duo-s8t.html is a **viewer page** for real-time translated captions. A host broadcasts speech captions via WebSocket; viewers join with a room link and see each sentence translated into their preferred language in real time.

- **One host, many viewers** (language exchange, remote meeting, classroom)
- **Auto-style selection**: 1 speaker → side-by-side, 2 → chat bubbles, 3+ → accordion tabs
- **Guest mode** (`?join=1`): read-only UI, no speaker management
- **Forward-only TTL switch**: changing translation language applies to new sentences only; past sentences stay as-is with a divider line

## 2. Architecture

```
caption-s8t.html (host)
    │  Mic → Speech API → WebSocket broadcast
    │  Message: {"msg":true, "final":"text", "id":N, "label":"A", "speaker":"Alice"}
    ▼
sottotitoli-websocket relay (Render)
    │  Room-based pub/sub. No auth per message.
    ▼
duo-s8t.html (viewer)
    │  WebSocket receive → translateAndAdd() → renderSentence()
    │  Translation: translation-providers.js (Google / MyMemory / Auto-fallback)
    ▼
DOM: adaptive layout (d1/d2/d3) + speaker sidebar + session persistence
```

### Data Flow Per Sentence

```
handleCaption(data)
  → validate (type check, 500-char cap, strip <> from speaker)
  → auto-register speaker if unknown
  → translateAndAdd(speaker, text)
      → T.translateText({provider}, text, srcLang, tgtLang)
      → addSentenceDirect(speaker, orig, translated)
          → push to DUO.sentences[]
          → renderSentence() → DOM
          → every 30 sentences → persistSession() → sessionStorage
```

## 3. DUO State Object (the single source of truth)

```javascript
var DUO = {
  style:     'd1',        // current display style: 'd1' | 'd2' | 'd3'
  slide:     1,           // active slide panel: 1=Transcript, 2=Speaker Cards, 3=Room
  session:   false,       // is session timer running?
  timer:     0,           // seconds elapsed
  timerInt:  null,        // setInterval handle
  roomId:    '',          // room identifier (e.g. "duo-a3x9k2")
  translations: 0,        // total translations done (counter only)
  ws:        null,        // WebSocket instance
  wsReconnect: null,      // setTimeout handle for reconnect
  myTTL:     'it',        // viewer's target translation language (ISO 639-1)
  srcLang:   'en',        // source language from URL param
  trProvider:'auto',      // translation provider: 'google' | 'mymemory' | 'auto'
  speakers:  {},          // {name: {snl, color, words, wpm, joined}}
  speakerOrder: [],       // ordered array of speaker names
  sentences: [],          // [{speaker, orig, tran, ts}] — unbounded in memory
  nextSpkId: 1,           // auto-increment for unnamed speakers
  connected: false,       // WebSocket connected?
  connecting: false,      // WebSocket connecting?
  isHost:    true,        // room creator = host; ?join=1 = guest
  hostSpeaker: null       // name of host speaker (cannot be deleted)
};
```

## 4. URL Parameters

| `?join=1` | `duo-s8t.html?join=1&room=duo-abc123` | Guest mode — read-only, must be logged in |

## 8. Function Reference

### Init & Connection

| Function | Scope | Purpose |
|----------|-------|---------|
| `init()` | Private | Entry point. Parses URL, checks auth for guests, calls `initAfterAuth()` |
| `initAfterAuth()` | Private | Loads preferences, restores session, connects WebSocket |
| `parseURLParams()` | Private | Reads `?join`, `?room`, `?src`, `?tgt`, `?host` from URL |
| `connectWebSocket()` | Private | Opens WebSocket to relay, sets up onopen/onmessage/onclose/onerror |
| `wsError()` | Private | Handles WebSocket errors, schedules reconnect (5s delay) |
| `updateStatus(state)` | Private | Updates room code display: idle/connecting/connected/disconnected/error |

### Caption & Translation

| Function | Scope | Purpose |
|----------|-------|---------|
| `handleCaption(data)` | Private | Validates incoming message, registers speaker, queues translation |
| `translateAndAdd(speaker, orig)` | Private | Calls `T.translateText()`, falls back to source-only on error |
| `addSentenceDirect(speaker, orig, tran)` | Private | Appends to `DUO.sentences[]`, renders DOM, triggers persist every 30 |

### Session Persistence

| Function | Scope | Purpose |
|----------|-------|---------|
| `persistSession()` | Private | Saves last 400 sentences + speakers + timer to `sessionStorage` |
| `restoreSession()` | Private | Restores from `sessionStorage` if saved today. Re-renders transcript |

### Speaker Management

| Function | Scope | Purpose |
|----------|-------|---------|
| `duoAddSpeaker(name, snl)` | Global | Host-only. Max 5. Auto-color from SPK_COLORS array |
| `duoRemoveSpeaker(name)` | Global | Host-only. Cannot remove host. Filters their sentences from array |
| `duoUpdateSpeakerSNL(name, snl)` | Global | Changes speaker's source language. Triggers re-render |
| `duoRenameSpeaker(old, new)` | Global | Renames speaker across speakers{}, speakerOrder[], and all sentences[] |
| `renderSpeakerConfigs()` | Private | Renders the settings panel with per-speaker name/lang inputs |
| `renderSpeakers()` | Private | Renders the left sidebar speaker list with avatars and status dots |
| `updateStyleForCount()` | Private | Auto-selects d1/d2/d3 based on `speakerOrder.length` |

### Display & Navigation

| Function | Scope | Purpose |
|----------|-------|---------|
| `renderSentence(speaker, orig, tran)` | Private | Creates DOM element per style (d1/d2/d3). HTML-escaped via `esc()` |
| `reRenderAll()` | Private | Clears transcript DOM, re-renders all sentences from `DUO.sentences[]` |
| `reTranslateAll()` | Private | ⚠️ **DO NOT auto-call.** Re-translates every sentence. API bomb. Exists for potential manual trigger only |
| `duoSetStyle(style)` | Global | Manual style switch. Updates buttons, re-renders |
| `duoGoSlide(n)` | Global | Switches slide panel (1–3). Triggers `renderSpeakerCards()` on slide 2 |

### Session Timer

| Function | Scope | Purpose |

## 9. Persistence Model (Tiered)

| Tier | Limit | Storage | Purpose |
|------|-------|---------|---------|
| **Memory array** | Unlimited | `DUO.sentences[]` | Live session — no data loss |
| **DOM nodes** | Unlimited | `#duoTranscript` children | Modern browsers handle thousands of simple divs |
| **sessionStorage** | Last 400 sentences | `sessionStorage['duo-session-' + roomId]` | Crash recovery. Saved every 30 sentences + on `beforeunload`. Expires after 24h |
| **localStorage** | Single values | `duo-room-id`, `duo-my-ttl`, `duo-tr-provider` | Preferences that survive across sessions |

## 10. Security Posture

### Current State (2026-08-04)

| Vector | Status | Detail |
|--------|--------|--------|
| **XSS (script injection)** | ✅ Protected | `esc()` HTML-escapes all user text before `innerHTML` |
| **Speaker name injection** | ✅ Protected | Angle brackets stripped in `handleCaption()`, plus `esc()` fallback |
| **Message spam / OOM** | ✅ Protected | 500-char per-message cap in `handleCaption()` |
| **WebSocket impersonation** | ❌ Vulnerable | `data.speaker` and `data.label` are trusted from wire. Anyone with room ID can inject fake captions as any speaker |
| **Room eavesdropping** | ❌ Vulnerable | Anyone with room ID can join silently and read all captions. No auth per WebSocket message |
| **Room ID enumeration** | ⚠️ Low risk | 36^6 = 2.1B combinations. But links shared via WhatsApp/Email bypass enumeration |

### Guidance

- **Safe for:** Private 1-to-1 links shared directly between trusted participants
- **NOT safe for:** Public rooms, social media links, classrooms with untrusted students
- **Fix before going public:** WebSocket relay must authenticate message senders (sign messages with Supabase session token)

## 12. Known Issues

| # | Issue | Severity | Status |
|---|-------|----------|--------|
| 1 | **N+1 translation cost** — every viewer calls `translateText()` independently. 20 viewers = 20× API calls per sentence | High | ⏳ Deferred. Fix: host-side pre-translate or relay-side cache |
| 2 | **WebSocket impersonation** — no message auth. Anyone with room ID can inject as any speaker | High | ⏳ Deferred. Fix: relay-side message signing |
| 3 | **`escAttr()` double-escaping** — speaker names with quotes may render HTML entities in rename inputs | Low | ⏳ Deferred. Only surfaces with `"` or `'` in names |
| 4 | **`reTranslateAll()` API bomb** — exists in code, not auto-called. Would hammer API if triggered | Medium | ⏳ Deferred. Add stagger + limit before exposing as UI button |
| 5 | **Viewer WPM inaccurate** — calculated from network receipt time, not actual speech time. Should be host-calculated and sent with message | Low | ⏳ Deferred |
| 6 | **No session persistence to Supabase** — `sessionStorage` only survives same-browser refresh. Full session history is lost between devices | Low | ⏳ Future |

## 15. Do NOT

1. **Never auto-call `reTranslateAll()`.** It re-translates every stored sentence with no batching. API death.
2. **Never change the WebSocket message format** (`{msg:true, final:"text", id:N, label:"A"}`). The relay and all clients depend on this.
3. **Never load scripts out of order.** `config.js` must come before `auth.js`.
4. **Never remove `esc()` from DOM rendering.** XSS protection depends on it.
5. **Never hardcode URLs.** Use `window.SOTTOTITOLI_CONFIG.websocketUrl` or the fallback.
6. **Never remove `data-theme` from `<html>`.** Theme toggle depends on it.
7. **Never commit `config.js`.** It's gitignored and contains production URLs.
