Microphone harness

Regression gate for the mic area. Run a server at the repo root and open /tests/mic-harness.html. Loads the real modules plus the real caption page in an iframe, and inspects window.__micHarness so it can also be read by a script.
The iframe emits a burst of 401s and "Expected 3 parts in JWT" warnings on localhost — that is the caption page talking to Supabase without a real session. Expected, and not a harness failure.
