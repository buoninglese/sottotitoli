01EN word suggestions (synonyms · antonyms · word-family · related · rhymes)

Datamuse

FREE
https://api.datamuse.com/words?ml=celebrate&max=20&md=p
Feeds: suggestion cards (all 5 relations), synonym chips inside cards, related words (rel_jjb), rhymes (lc=). Called client-side, up to ~25 requests per search session.
Rating★★★★★4 / 5Cost$0 · no key
GET /words?ml=celebrate&max=20&md=p
[
  { "word":"commemorate", "score":33972, "tags":["syn","v"] },
  { "word":"observe",      "score":15846, "tags":["syn","v"] },
  { "word":"fete",          "score":8432,  "tags":["syn","v"] }
]
Strengths: instant, no auth, tags carry POS + frequency. Limits: English only, no definitions, quality degrades on rare words.

02EN definitions + IPA (dictionary card)

Free Dictionary API → Wordnik (fallback)

FREE
https://api.dictionaryapi.dev/api/v2/entries/en/celebrate
Feeds: .wbx-def (definition text), .wbx-ipa (phonetic), POS label. Primary = Free Dictionary; on miss → Wordnik via Supabase edge proxy (key server-side).
Rating★★★★★3 / 5CostFREE + key for Wordnik
GET /api/v2/entries/en/celebrate

   "phonetic":"/ˈsɛləˌbɹeɪt/",

Strengths: keyless, clean JSON, IPA present. Weakness: phonetics missing on many words, thin on rare/domain terms → Wordnik covers gaps.

Feeds: .wbx-def (first real definition line), POS label (parsed from === Sostantivo ===), grammar (m/f sing/pl).
Rating★★★★★3 / 5CostFREE

FREEMIUM

Feeds: .wbx-trans chips on every card — English tab uses en|it, Italian tab uses it|en. Chips are clickable (+ saves to the right bank).

Rating★★★★★4 / 5CostFREE TIER → paid scale
