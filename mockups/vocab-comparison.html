Recommendation
Use the server-side approach. Same quality, same cost ($0), but with DB caching that makes repeat lookups 4-8× faster. The only tradeoff is ~100ms slower on first lookup, which is imperceptible. For Italian vocabulary later, the server-side path is the only viable option — client-side Italian dictionaries don't exist as clean APIs.
