How translation works

You choose one target language — this is the language all captions will be translated into.

Your speech input can be in any supported language, even when multiple speakers talk in different languages.

Sottotitoli detects the source language automatically and translates everything to your chosen target.
Mode Selector — three ways to choose

Instead of "Universal → IT | FR | DE", the mode is a separate choice. Universal = auto-detect any source → one target. Single-lang = one known source → one target. Multi-lang = each speaker → their own target.

Options: ← no arrow, just choices
