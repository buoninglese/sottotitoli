Design System Tokens Components

Typography Scale

Every font-size in the system maps to one of these tokens. Never use raw px values. All sizes are in the --fs-* custom property set.

--fs-hero Hero 60px Cormorant Garamond · page hero, banners
--fs-h1 H1 48px Inter 600 · panel/page titles
--fs-h2 H2 24px Inter 600 · card headings (alt-card h3)
--fs-h3 H3 18px Inter 600 · subheads, tab links, list rows
--fs-body Body 16px Inter 400 · paragraphs, list items, descriptions
--fs-ui UI 14px Inter 400-600 · labels, nav items, dropdowns, field inputs
--fs-cap Caption 12px Inter 400-600 · subtitles, hints, secondary info, field labels
--fs-fine Fine 11px Inter 400 · only for tertiary metadata, badges, spec labels

Special-purpose sizes — used only in specific components:

--fs-metric Metric 30px metric-card .metric-value
--fs-habit Habit 28px habit-item .hv
--fs-btn Button 17px .primary-btn, .hero-chip
--fs-chip Chip 13px .q-chip tags
--fs-brand Brand 28px .topbar-brand logo
