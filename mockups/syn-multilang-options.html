📋 Options for Non-English Languages

🔷 Option A: Local Dictionary

Build IT/FR/DE/ES/NL/PT dicts
📖Create synonym dictionaries per language (like SYN_DICT for EN, IT_SYN_DICT for IT)~200 words each
⚡Instant lookup, no API cost
🔗Word Bank works universally
⏱Time: 1-2h per language to build initial dict

🔶 Option B: Wiktionary API

External API per language
🌐Fetch synonyms + definitions from Wiktionary REST APIAll languages
📡Live data, always up-to-date, no maintenance
🐢Slower (network round-trip), may rate-limit
⚠️CORS may require proxy for some languages

🔷 Option C: Google Translate Backfill

Translate EN synonyms
🔄Use EN synonym dict, Google-translate each synonym to target languageMay lose nuance
⚡Works for ALL 7 languages instantly
💰Free (Google Translate web endpoint)
🎯Quality varies — Italian OK, Dutch worse

🔶 Option D: Datamuse Multi-Lingual

Datamuse for definitions only
📖Datamuse has English definitions. Use local dicts for synonyms.
🏗️Build ES/FR/DE synonym dicts from open data (OpenThesaurus, etc.)
⏱Hybrid: definitions from API, synonyms from local dict
