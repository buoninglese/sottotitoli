📝 Transcript Box — 15 Holistic Mockups

Reimagining the sentence-history panel: selectable · editable · animated · space-aware

What this box does: Shows previous sentences so the user can review, select for analysis, and correct transcription errors by clicking individual words. Each mockup explores a different approach to layout, density, selection UX, word-level editing, and entry animation.
Try: Hover any sentence → click the ✎ edit icon (most variations) → click a word to see the editor. Selected sentences show a purple highlight. Every word is individually hoverable.
