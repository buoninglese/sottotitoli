✅ DECISION: Google Translate (free endpoint) as sole provider.

MyMemory dropped — inconsistent quality, TM-based gibberish on novel sentences.

Current implementation: `translation-providers.js` → `translateWithGoogle()` via the free translate.googleapis.com endpoint. Queued processing (200ms spacing) to avoid rate limiting. Falls back to showing source text if Google fails.

Future upgrade path: DeepL API for premium quality (500K chars/month free covers light use). Google Cloud Translation v3 for SLA + glossaries if scale demands it.
