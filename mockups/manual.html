How to use the site

Sottotitoli Manual

Sottotitoli is a live English–Italian captioning and translation tool with five modes: two caption modes, two translation modes, and one lesson mode with report generation.

Back to homepage

Modes

  • Live Caption English: English speech to English captions.
  • Live Caption Italian: Italian speech to Italian captions.
  • Translate EN → IT: English speech with Italian output.
  • Translate IT → EN: Italian speech with English output.
  • Lesson Mode: capture a session and generate a simple lesson report.

How to start

  • Open the homepage and choose a mode.
  • Click Start microphone.
  • Allow microphone access in the browser.
  • Use Open overlay to display the public live output page.
  • Use Copy overlay link when you want to share the display page quickly.

Lesson workflow

  • Open Lesson Mode from the homepage.
  • Run the lesson as normal and keep speaking output captured.
  • Click Generate report when the session ends.
  • Copy or download the transcript and report for later review.

Current limits

  • Speech recognition depends on browser support, especially Chromium-based browsers.
  • Translation output may remain limited until a stronger live provider is wired in.
  • The lesson report is currently local and rule-based, ready for later AI enhancement.
