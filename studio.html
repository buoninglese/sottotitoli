Reports and analysis guidance

The reporting stack now has three clear layers so users understand what each analysis does and when to use it.

Lesson report

Session summary guidance

  • Use this after a session to generate a written summary from the captured transcript.
  • Best for reviewing content, clarity, pacing, and what happened during the session.
  • Good first layer before going into deeper speaker or AI analysis.
Speaker analysis

Diarization guidance

  • This uses the recorded session audio, not just the visible text stream.
  • Best for speaker turns, interruptions, talk share, and segment-level speaker structure.
  • Stop the microphone first so the audio file is complete before starting analysis.
AI report

Premium analysis guidance

  • This section is for deeper paid or token-based reporting in the future.
  • Use it for more personal, profile-aware analysis once Obiettivi and training data are connected.
  • Position this as the analysis ground, not as a generic transcript summary.
